# Reporting a security issue

Use **Security → Advisories → Report a vulnerability** on the GitHub repository to contact the maintainers privately. Include the affected version or commit, operating system, expected and actual behavior, and the smallest example that demonstrates the issue. Use fictional data. Keep provider credentials, customer material and unredacted logs out of reports.

Report ordinary bugs in GitHub Issues. Read the [README](README.md) for local storage and provider behavior.
