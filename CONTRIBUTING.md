# Contributing

Open an issue for a bug or proposed change. Include the Windows version, the FaiBots version or commit, and clear steps to reproduce. Use fictional notes and redact file paths, account details, provider credentials and logs.

Keep changes focused and explain how you verified them. Run `npm run typecheck`, `npm test` and `npm run build` before submitting a pull request. See [third-party notices](THIRD_PARTY_LICENSES/README.md) before editing or reusing licensed components.

Use the [private security reporting process](SECURITY.md) for a security issue.
